### ✅ **Final Projects

#### 1. **Personal Portfolio Website (Advanced Version)**

**What to build:**
- Multi-page site (Home, Projects, About, Contact)
- Responsive design using Flexbox/Grid or Tailwind/Bootstrap
- Form with validation (Contact form)
- Interactive elements using JavaScript (e.g., project filtering, dark mode toggle)
- Host on GitHub Pages/Netlify

---

#### 2. **Interactive Product Showcase Website**

**What to build:**
- Landing page for a fictional product (e.g., smartwatch, smartphone, software)
- Interactive gallery or product slider
- “Buy Now” form with validation
- Responsive layout using a CSS framework
- JavaScript-powered modal for product details

---

#### 3. **Task Manager Web App**

**What to build:**
- CRUD to-do/task manager (Create, Read, Update, Delete tasks)
- Responsive interface with form validation
- Store tasks in `localStorage`
- Use Bootstrap or Tailwind for UI
- Bonus: Add filters, sorting, and light/dark mode

---

#### 4. **Simple Blog Website**

**What to build:**
- Homepage with a list of blog posts
- Individual post pages using separate HTML files
- JavaScript to handle dynamic behaviors (e.g., search/filter posts)
- Responsive layout
- Basic animations for transitions (CSS)

---

#### 5. **Quiz Web App**

**What to build:**
- Multiple-choice quiz
- Timer and score system
- Show correct/incorrect answers using JavaScript
- Responsive design for mobile and desktop
- CSS animations for feedback
